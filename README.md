# Program 2: Structured Question Answering System

## 📌 Overview
This project implements a structured representation-based question answering system. Instead of using simple pattern matching, it converts both text and questions into structured internal forms and matches them to extract answers.

## 🧠 Key Concepts
- Structured Representation
- Knowledge Base
- Rule-Based AI
- Early Natural Language Processing

## 🛠 Technology Used
- Python

## ▶ How to Run
1. Install Python
2. Run the program:
3. Enter a question related to the stored knowledge.

## 🧪 Example
**Question:** What did Mary buy  
**Answer:** a red coat

## ⚠ Limitations
- Limited vocabulary
- Manual structure creation
- No real language understanding

## 📚 Learning Outcome
- Difference between text matching and structured AI
- Importance of internal representation in AI systems
